## 2. Description of Service

MeshBoard provides an offline-first peer-to-peer bulletin board utility designed to relay public text announcements between nearby compatible Android devices using local radio connections (Bluetooth and Wi-Fi Direct). The App functions without internet access, mobile data, or central servers.
